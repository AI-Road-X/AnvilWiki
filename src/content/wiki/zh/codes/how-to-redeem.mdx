## Aniimo 兑换码入口在哪里？

[Pocket Tactics](https://www.pockettactics.com/aniimo/codes)、[Dexerto](https://www.dexerto.com/wikis/aniimo/codes/) 与 [PC Gamer](https://www.pcgamer.com/games/rpg/aniimo-codes/)报道的路径是 **Settings → Account → Gift Code Redemption**。本站于 2026 年 10 月 22 日重新查阅这些说明，没有操作游戏实测。快捷键和截图可能只适用某个平台，更新后的客户端提示优先。

1. 打开游戏主菜单。PC Gamer 展示的是 PC 的 Esc 键，不代表主机与手机也使用这个快捷键。
2. 进入 Settings，选择 Account，再找 Gift Code Redemption。
3. 输入代码，保留大小写并删除首尾空格。
4. 提交一次，先看清游戏原始提示，再决定下一步。
5. 如果兑换被接受，进入 Mail 打开邮件并领取；代码被接受与奖励已领取是两回事。

输入前先查[媒体报道代码及证据状态](/zh/codes/getting-started/)。攻略标题或近期复核日期都不保证当前有效，更不要在第三方“代兑换”网页输入账号密码。

## 为什么找不到邮箱或兑换菜单？

不同来源的解锁条件不能混为一谈。Dexerto 提到完成开头教学后才开放兑换菜单；PC Gamer 则把邮箱开放与 Dr. Lewis 的 **Chasing The Clouds** 任务关联。这些是媒体报道，不能当成所有后续版本都适用的官方任务规则。

分别检查任务完成状态和菜单是否开放。[邮箱解锁说明](/zh/quests/chasing-the-clouds/)解释了两者的区别；如果当前游戏写明不同条件，以客户端为准，不要因为旧截图重做无关任务或换账号。

## 代码失败或奖励未到账，应该先查什么？

先按游戏的实际提示分类：代码被拒绝、已经领取、兑换被接受但没收到邮件，不是同一个问题。可以私下记录提示、服务器、平台和时间，便于客服定位；一个账号失败也不能直接证明该代码全球过期。

| 实际情况 | 下一步检查 |
| --- | --- |
| 代码被拒绝 | 拼写、大小写、首尾空格、来源与当前领取期限 |
| 提示地区限制 | 当前服务器是否符合报道限制；不要只为候选奖励换服 |
| 提示已领取 | 领取记录和邮箱；重复提交不等于还能再领一次 |
| 接受代码但没有 Mail | 当前客户端中的教学与任务完成状态 |
| 已有邮件但找不到物品 | 打开邮件并点击领取，再核对相关背包或货币余额 |

PC Gamer 建议等待几分钟；五分钟后仍没有邮件时，可尝试快速旅行或重启。这是第三方上线排查经验，**不是官方保证的到账时限**。问题持续时，从当前游戏的客服入口反馈原始提示、时间、服务器和平台，不要提供密码或恢复代码。

## 活动或上线奖励也需要兑换码吗？

不一定。先用[官方上线奖励参考](/zh/guides/official-launch-rewards/)区分活动、登录和里程碑领取渠道。核对账号与资格后再找缺失的代码；重复输入无关字符串不能恢复已结束的活动窗口。

按[开局检查清单](/zh/guides/launch-day-checklist/)检查不同奖励渠道。本站不提供付费代领或账号核验服务；排查奖励不需要下载代码工具、分享密码或支付领取费用。
