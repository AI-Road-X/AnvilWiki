## Aniimo 067 是谁？

No.067 对应 **Infergon**。官方基础形态列为火属性 DPS，Prismana 页面则列出火、风双属性，两者总属性均为 505。增加属性是已确认的形态差异，但不能据此断言 Prismana 面板更高或实际输出排名更高。

| 项目 | 官方资料 |
| --- | --- |
| 名称 | Infergon |
| 编号 | No.067 |
| 属性 | 火 |
| 定位 | DPS |
| 总属性 | 505 |
| HP / BREAK / ATK | 95 / 50 / 125 |
| M.DEF / P.DEF / REGEN | 85 / 70 / 80 |
| 移动能力 | Fly Lv.2 |
| 形态页面 | Basic Form、Prismana Form |

官方描述称 Infergon 身披火焰锻造的盔甲，吐息的火焰足以熔化几乎一切。官方页面展示了 Gamma 与 Nova 阶段的进化插图；此形态页面没有列出栖息地，因此这里不推测其出现地点。

| 形态 | 官方列出的属性 | 总属性 |
| --- | --- | ---: |
| [Basic](https://wiki.aniimo.com/item/067/basic-form) | Fire | 505 |
| [Prismana](https://wiki.aniimo.com/item/067/prismana-form) | Fire、Wind | 505 |

封面为本站原创形态对照示意图，不是官方立绘或实机截图。另一位火属性 DPS 可对照 [Scorchhowl 的技能条件](/zh/characters/scorchhowl/)，但属性相同不代表连招机制相同。

## 特性与战斗机制

**Power of Fire** 会对拥有超过 5 层 Fire Debuff（火焰减益）的目标造成额外 30% 伤害。Lava Breath 和 Hot Breath 都能施加 8 层火焰减益，因此可以直接配合这项特性。以上为官方特性与技能说明，不代表固定强度排名或配队保证。

“超过五层”指至少六层，不包括五层。只做层数算术示例：八层消耗两层后剩六层，再消耗两层就剩四层。这不是实测连招；官网说明没有完整交代持续时间、伤害结算顺序及所有交互，不能保证整套连招始终享有加成。
