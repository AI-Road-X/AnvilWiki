| 项目 | 官方资料 |

| 属性 | Wind、Electric |
| 角色定位 | Support |

| HP / BREAK / ATK | 80 / 43 / 84 |
| M.DEF / P.DEF / REGEN | 82 / 69 / 93 |
| 进化阶段 | Lumin、Gamma |
| 栖息地 | Nimbus Fields |

吸收水分会改变 Nimbi 的毛色，并使毛发具备导电性，可以储存闪电。官方页面列出了 Basic、Rainstorm、Cloudmist 和 Plateau Form。

## 移动能力、特性与技能

- **Fly Lv.1**：支持基础飞行移动。
- **Shrouded in Mist**：使用 4 次普通攻击后进入该状态；施放技能会消耗状态并强化技能效果。

| Thunder Bolt | Magic | 10 | 30 |
| Cloud Shield | Support | 20 | 0 |
| ATK | Magic | 0 | 6 |
