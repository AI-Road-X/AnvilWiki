## 形态范围与基本资料

本文记录 **Prismana 形态**。官方页面同时列出 Basic 与 Prismana 两种形态；下方数值和技能来自 Prismana 形态条目，不应直接视为 Basic 形态资料。

| 项目 | 官方 Prismana 形态资料 |
| --- | --- |
| 名称 | Fulmintis |
| 编号 | No.10003 |
| 属性 | Holy / Electric |
| 定位 | DPS |
| 属性总值 | 520 |
| HP / BREAK / ATK | 99 / 50 / 130 |
| M.DEF / P.DEF / REGEN | 70 / 66 / 105 |
| 路径能力 | Fly Lv.2 |
| 移动能力 | Hide |

官方描述称，Prismana 能量赋予 Fulmintis 新的力量，使它化作战场上的红色疾影。

## 特性与战斗提示

- **Electric Storage**：技能造成暴击时回复 4 EP。
- **Hide**：进入隐藏状态。

特性可通过暴击回复 EP。该官方形态页面没有列出栖息地。
