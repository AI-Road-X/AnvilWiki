## 基本资料

| 项目 | 官方资料 |
| --- | --- |
| 名称 | Cubbo |
| 编号 | No.068 |
| 属性 | 岩 |
| 定位 | DPS |
| 总属性 | 435 |
| HP / BREAK / ATK | 92 / 42 / 100 |
| M.DEF / P.DEF / REGEN | 61 / 70 / 70 |
| 栖息地 | Rosetower Woods |
| 已展示进化阶段 | Lumin、Gamma |

官方描述称 Cubbo 白天会梦游，被叫醒后会变得暴躁失控；耗尽能量后又会像婴儿一样睡着。

## 移动能力与 Rage 特性

- **Head Hammer：** 使用移动技能发出冲击波。
- **Raging Rampage：** Cubbo 会在战斗中积累 Rage。普通攻击和受到伤害各获得 2 点；技能每消耗 10 EP 获得 10 点。达到 100 点后进入 Enraged 状态，持续 20 秒：攻击速度和自身技能伤害提高 30%，EP 回复速度提高 25%，并且状态期间不再获得 Rage。

上述 Rage 来源意味着它可以在正常交战过程中积累状态；持续时间和增益数值均按官方描述整理。
