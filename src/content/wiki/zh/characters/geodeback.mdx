## Aniimo 073 是谁？

No.073 对应 **Geodeback**，官方列为岩属性、BREAK 定位，总属性为 486。其主要机制是 Tunnel 与 Earth Affinity 的配合。下表记录基础形态公开面板，不是捕捉路线，也不是与所有 BREAK 角色实测比较后的排名。

| 项目 | 官方资料 |
| --- | --- |
| 名称 | Geodeback |
| 编号 | No.073 |
| 属性 | Rock |
| 定位 | BREAK |
| 属性总值 | 486 |
| HP / BREAK / ATK | 99 / 102 / 81 |
| M.DEF / P.DEF / REGEN | 54 / 80 / 70 |
| 页面列出的进化阶段 | Lumin、Gamma、Nova |
| 移动能力 | Tunnel |

官方描述称，Geodeback 吃下的矿物会重新长在身上，内部储存着提炼后的能量。官方 Basic Form 页面没有列出栖息地，因此本文不推测其地点。

## 移动能力与特性

- **Tunnel**：钻入地下，在持续消耗耐力的同时免疫远程攻击；Pound 类技能可以把 Aniimo 击飞。
- **Earth Affinity**：处于 Tunneling 状态时仍可施放技能，并额外造成 20% BREAK。

官方说明针对的是远程攻击，并未声称此状态能挡下所有类型的攻击。封面以本站原创示意图展示这些条件，不代表实机测试。

实战需要分开检查两个条件：当前是否处于 Tunneling 状态，以及耐力能否继续维持。不要把状态限定的加成直接写成常驻增伤。来源还提到 Pound 技能可以将其击飞，因此遁地不代表免疫所有打断方式。[Tuckin 的 Mountain 形态](/zh/characters/tuckin/)采用 Hummin 召唤机制，不应把另一角色的规则套用到 Geodeback。
