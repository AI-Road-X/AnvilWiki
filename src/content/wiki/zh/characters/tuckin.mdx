## Aniimo 022 是谁，本页写的是哪个形态？

No.022 对应 **Tuckin**。本文记录官方 **Mountain Form**，该形态列出岩、草双属性和 BREAK 定位。官网同时链接到 Basic Form，不能不分形态地套用 Mountain 的属性标签。下表是公开资料，不是本站实测配装。

| 项目 | 官方资料 |
| --- | --- |
| 名称 | Tuckin |
| 编号 | No.022 |
| 本页形态 | Mountain Form |
| 属性 | Rock、Grass |
| 角色定位 | BREAK |
| 属性总值 | 550 |
| HP / BREAK / ATK | 106 / 100 / 80 |
| M.DEF / P.DEF / REGEN | 110 / 83 / 71 |
| 进化阶段 | Lumin、Gamma |

官方描述称，土地成分变化使 Tuckin 吸收矿物后拥有橙红色、更加厚实坚硬的皮肤。

## 特性与技能

- **Prank Master**：进入战斗召唤一只 Hummin，此后每十秒再召唤一只，最多三只。生命值缩放条款提到每 21,000 点最大 HP，但公开文本的百分比留空，因此无法计算 BREAK 加成，也不能据此推荐生命值目标。

表格中的 HP 属性 106 不是官方宣称的“实战最大生命值为 106”。直接把属性代入每 21,000 点最大 HP 的条款，会混淆不同数值。召唤上限也不代表开场固定三只或可以无限召唤。封面原创示意图仅展示单位持续存在时的召唤数量，不是实测时间轴，也没有补造缺失倍率。

| 技能 | 类型 | 消耗 | 威力 |
| --- | --- | ---: | ---: |
| Draw Nourishment | Support | 30 | 0 |
| Haunting Choir | Magic | 20 | 47 |
| Gravel Strike | Physical | 10 | 39 |
| Off-Key Shock Wave | Magic | 10 | 39 |
| Breaking Roar | Physical | 0 | 165 |
| ATK | Physical | 0 | 6 |

## Hummin 相关技能有什么作用？

Draw Nourishment 支援 Tuckin 与 Hummin，公开的治疗目标不代表能为无关队友提供全队治疗。Haunting Choir 让 Hummin 移动到目标身边，进行带一秒眩晕的范围攻击；Breaking Roar 则先恢复 Hummin 数量再一同攻击。安排连招前，请核对当前技能文本与可用单位。

相关生物自身的资料见 [Hummin 图鉴](/zh/characters/hummin/)；另一种 BREAK 机制可对照 [Geodeback 的遁地条件](/zh/characters/geodeback/)。相同定位或机制比较都不能直接证明最佳配队或固定排名。
