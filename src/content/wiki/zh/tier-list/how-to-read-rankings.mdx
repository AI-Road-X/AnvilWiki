## 怎样比较一次培养变化，而不猜字母等级？

先确定一个问题和一个拟议变化，再写清哪些条件保持一致。本页是可核对的决策工作表，不是第二份全局强度榜。尚未确定功能时，先用[按用途筛选候选](/zh/tier-list/getting-started/)缩小范围。

| 字段 | 记录内容 |
| --- | --- |
| 目标 | 某个玩法中的一个可观察问题 |
| 现有／候选 | 名称和准确形态 |
| 固定条件 | 队伍、目标、等级、装备、游戏版本 |
| 公开差异 | 同名属性或明确技能条件 |
| 实际观察 | 真正发生的结果；测试前留空 |
| 资源代价 | 消耗、时长、恢复限制 |
| 决定 | 保留、继续研究或暂缓，并说明原因 |

账号相关细节放在私人记录里。设计了一个测试，不代表测试已经完成。

## 一份填好的 BREAK 比较是什么样？

用 [Geodeback Basic](/zh/characters/geodeback/) 对比 [Blazen Basic](/zh/characters/blazen/)，能看到为何总值不是整个决定。下表来自对应条目的官方资料，观察栏故意不填写不存在的测试结果。

| 字段 | Geodeback Basic | Blazen Basic |
| --- | --- | --- |
| 公开总值／BREAK | 486／102 | 530／104 |
| 相关机制 | Tunneling 期间 Earth Affinity | Power Sustain／Overcharged |
| 检查条件 | 遁地与足够体力 | 六次技能暴击 |
| 代价或风险 | 体力消耗，Pound 可击飞 | 六秒状态内不能获得 UP |
| 实际 BREAK 表现 | 本文未测量 | 本文未测量 |

总值差 **44**、BREAK 差 **2**，都不是实测伤害提升。更有用的下一步是观察：自己关心的窗口里，相关状态是否真的生效。无法重现条件时，按常驻增益估算就会歪曲比较。

## 治疗问题怎样使用同一张表？

对于 [Bulbly](/zh/characters/bulbly/)，记录队友元素、位置与光束是否持续。目标不符合公开条件，和目标符合却没有效果，是两个问题；本体施法也应与撤退分身行为分开。

另一种辅助 [Cozite](/zh/characters/cozite/)提供抗性减益与烟幕目标限制，不是已记载的治疗。仅凭两者都叫 Support 就互换，会连测试功能一起改变。应先确认自己究竟缺什么。

## 什么情况下应该暂缓结论？

无法固定玩法、形态不可比、不知道获取成本、还没观察到结果时，应暂缓“谁更强”的结论。这不妨碍你使用喜欢的角色，只限制本文能证明什么。

看到别处不同排名时，先检查其玩法是否相同、证据是否解释了差异，不把不兼容的字母等级取平均。[核验说明](/zh/characters/verification-notes/)区分来源与观察；空着的测试栏比虚构最优配装更有用。
