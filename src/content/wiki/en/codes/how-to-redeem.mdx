## Where is the redemption menu?

The menu path reported by [Pocket Tactics](https://www.pockettactics.com/aniimo/codes), [Dexerto](https://www.dexerto.com/wikis/aniimo/codes/) and [PC Gamer](https://www.pcgamer.com/games/rpg/aniimo-codes/) is **Settings → Account → Gift Code Redemption**. We reviewed those published instructions on October 22, 2026; we did not operate the game. Treat screenshots or keyboard shortcuts as platform-specific, and follow the current client if its labels differ.

1. Open the game's main menu. PC Gamer shows Esc on PC; that is not a universal console or mobile shortcut.
2. Open Settings, select Account, and look for Gift Code Redemption.
3. Paste or type the code, preserve capitalization, and remove extra spaces.
4. Submit once and read the exact response before trying again.
5. If accepted, open Mail and claim the delivered reward; acceptance and collection are separate steps.

Check the [reported-code list and evidence status](/codes/getting-started/) before entering a string. Neither a guide's headline nor a recent review date guarantees current availability. Do not enter credentials on an outside site claiming to redeem the code for you.

## Why is Mail or the redemption option missing?

The cited guides describe an early-game unlock, but their statements are not interchangeable. Dexerto mentions finishing the opening tutorial before the code menu becomes available. PC Gamer links the mail unlock to **Chasing The Clouds** with Dr. Lewis. These are reported conditions, not a verified universal quest rule for every later build.

Check quest completion and menu availability separately. The [mailbox unlock guide](/quests/chasing-the-clouds/) explains the distinction. If the current game points to a different condition, follow it instead of replaying an unrelated task or changing accounts based on an old screenshot.

## What should I check when a code fails?

Match the next check to the actual response. A rejected string, a previously claimed reward, and accepted-but-missing mail are different problems. Copy the message into a private note with your server and platform so support can distinguish them. Do not conclude that a code has expired for everyone from one account's result.

| What happened | Useful next check |
| --- | --- |
| The code is rejected | Exact spelling, capitalization, spaces, source and current claim window |
| A region restriction is shown | Whether your server matches the published restriction; do not switch servers just for a candidate |
| The game says already claimed | Claim history and mailbox; repeated submissions do not establish another entitlement |
| The game accepts it, but Mail is unavailable | Tutorial and quest completion in the current client |
| Mail exists, but the items seem missing | Open the message, use its claim control and recheck the relevant inventory or balance |

PC Gamer suggests waiting a few minutes, then fast traveling or restarting if accepted rewards do not appear after five minutes. This is third-party launch troubleshooting, **not an official delivery-time guarantee**. If the problem persists, use the current in-game support channel and provide the response, time, server and platform without exposing passwords or recovery codes.

## Do I need a code for an event or launch reward?

Not every gift uses the redemption menu. The [official launch rewards reference](/guides/official-launch-rewards/) records event, login and milestone routes separately. Check the account and event eligibility before searching for a missing code; an expired event window cannot be fixed by repeatedly submitting an unrelated string.

Use the [launch-day checklist](/guides/launch-day-checklist/) to review those separate reward paths. This guide does not sell redemption services or verify accounts, and no troubleshooting step requires downloading a code tool, sharing your password or paying a claim fee.
