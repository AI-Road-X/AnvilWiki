## What does Dazmand contribute to a Lightning team?

Dazmand offers an EP-saving opening and a hit-dependent offensive team buff. It is listed as Lightning Support, but that label does not establish a healing ability. Choose it to investigate those specific functions; for healing eligibility, compare [Bulbly](/characters/bulbly/) and [Veilfloat](/characters/veilfloat/) instead.

| Official number / role | No.10002 / Lightning Support |
| Total | 522 |
| HP / BREAK / ATK | 100 / 55 / 108 |
| M.DEF / P.DEF / REGEN | 90 / 81 / 88 |

These are reference attributes, not measured combat output or a ranking. The official page does not provide a capture route here.

## How should you use the five-second opening?

Spotlight Moment applies to the first skill used within five seconds after entering battle, with a stated fifteen-second cooldown. Plan which action should receive the EP saving before entry. The wording does not promise that every skill during the window is free, nor that animations or other cooldowns disappear.

1. Note your EP immediately before entry.
2. Enter battle and use the intended first skill inside the window.
3. Check EP expenditure and the skill's actual effect separately.
4. If another action happened first, re-evaluate which skill consumed the opportunity.

## Which skill gives the team buff, and which checks Paralysis?

Thunder Sweep provides the team Lightning critical-rate effect on a hit; Electricity Shock uses a debuff threshold. Their conditions answer different questions. A cost-free opening can still miss, and an applied debuff is not automatically enough to pass a strict greater-than threshold.

| Skill | Listed cost / power | Important condition |
| --- | --- | --- |
| Thunder Sweep | 30 / 80 | Hit; team Lightning critical rate +20% for 20s |
| Electricity Shock | 20 / 40 | Adds five Lightning Debuff stacks; checks the resulting count for more than five |
| Lightning Storm | 0 / 150 | Twelve listed hits, each applying one stack |

For a simple arithmetic check, zero existing stacks plus five gives five, which does not satisfy “more than five.” One existing stack plus five gives six if all stacks remain and apply. This is a threshold example, not proof that a target accepts Paralysis: the page lists five seconds, but does not establish every enemy's resistance.

The displayed power of Lightning Storm is not explicitly described as a per-hit value. Multiplying 150 by twelve would therefore create an unsupported damage estimate.

## What should you compare before spending resources?

Record the opening action, whether it connected, the debuff count after the hit and the observed control result. This separates a failed trigger from an unsuitable build.
