## How do you find an Aniimo character?

Start with the [Aniimo character compendium](/characters/), then open the entry whose name or official number matches the one you are checking. Use the entry as a reference, not as proof of details it does not document. If names, abilities, or forms differ between sources, check the site's [verification notes](/characters/verification-notes/) before treating a claim as confirmed.

## What should you compare?

Compare like with like: the same form, activity, and game version. Look for the source and update context behind a claim, and separate official facts from community observations. A tier placement is an opinion unless its criteria and evidence are explained; see the [Aniimo tier list guide](/tier-list/getting-started/) for a cautious comparison checklist.

## Where should you go next?

Use the [official Aniimo types reference](/characters/official-aniimo-types/) when you need terminology, and consult the [quest guides](/quests/) or [catch-tool reference](/items/official-catch-tools/) when a character question depends on progression or capture resources. These references answer different questions, so avoid inferring an ability or location from a character name alone.
