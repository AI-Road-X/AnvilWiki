## Who is Aniimo 077, and what can Bulbly support?

No.077 is **Bulbly**, listed as Lightning and Support. Its key healing condition is the recipient's element and position, not simply membership in the same team. If you need help for a teammate of another element, check the wording before spending resources on a replacement.

| M.DEF / P.DEF / REGEN | 63 / 63 / 90 |
| Habitat / mobility | Tideblossom Coast / Glow |

[Official Basic Form source](https://wiki.aniimo.com/item/077/basic-form), checked October 27, 2026. Attribute totals are not a measured healing score; the HP attribute is not enough to calculate a combat heal.

## Who does Lightning Discharge heal?

Lightning Discharge is a channeled beam. The source specifies **Lightning-type teammates within range**, healed for **2% HP each second**. Its listed cost/power is **10/20**; the description does not establish whether that cost is a one-time or repeated channel expense.

Use three checks when diagnosing a missing heal: does the recipient meet the element condition, are they still in range, and is the channel actually continuing? This is a troubleshooting sequence, not a claim that any one check guarantees a successful cast. No numeric range is published here.

For a related support reference, compare [Luminelle](/characters/luminelle/), especially its separately described healing targets. Do not transfer a broader target rule from one named skill to another. The [type reference](/characters/official-aniimo-types/) separates element labels from combat roles.

## Does Swift Retreat make the clone a team healer?

The official text describes a backward retreat and a clone that attacks using Lightning Discharge, slowing targets by **15% for 10 seconds**; cost/power is **20/53**. It does not explicitly state that the clone inherits every support effect or heals every element.

Record the player-controlled cast and clone behavior separately if testing them. A shared skill name is a reason to investigate, not proof that both implementations share targeting, equipment, healing or duration rules. There is no tested clone build on this page.

## Why is no Arc Surge percentage recommended here?

The source's Arc Surge line prints **12%%**, with a duplicated percent sign. It ties a Lightning-damage benefit to teammates receiving a skill buff and gives a 20-second duration. We preserve that uncertainty instead of silently converting the malformed field into a verified build multiplier.

The issue affects confidence in the number, not the creature's identity. Check the current in-game wording before relying on that percentage. Our [verification notes](/characters/verification-notes/) explain how published text differs from independently checked behavior.
