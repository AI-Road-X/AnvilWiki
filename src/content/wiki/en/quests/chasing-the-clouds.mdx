## Quick answer: finish Chasing The Clouds with Dr. Lewis

If a code was accepted but you cannot find its reward, first check whether **Chasing The Clouds** is complete and whether the in-game Mail menu is available. [PC Gamer's September 2026 redemption guide](https://www.pcgamer.com/games/rpg/aniimo-codes/) reports that completing this story quest with Dr. Lewis unlocks the mail menu used to claim code rewards. This quest-specific unlock detail is third-party reporting, not a published official quest rule. [Aniimo's launch announcement](https://www.aniimo.com/newslist/detail/100115) separately confirms that rewards from official events are delivered through in-game mail.

## Unlock the mailbox

1. Open the in-game quest journal and check the completion state of **Chasing The Clouds**.
2. If it is still active, continue its objectives with Dr. Lewis; reaching a nearby town or area is not necessarily the same as completing the quest.
3. After it is marked complete, open the main phone or pause menu and look for Mail.
4. Open the reward message and use its claim action. Check that the message is claimed rather than assuming delivery automatically added the items to your inventory.

## Aniimo mail or code reward missing: what to check

| What you see | Next check |
| --- | --- |
| Mail is not available | Confirm that Chasing The Clouds is complete in the current game version. |
| The code is rejected | Recheck the exact spelling, capitalization, and any extra spaces; then confirm the code is still listed as usable. |
| The code was accepted but no message appears | Wait a few minutes. PC Gamer advises trying a fast travel to another area if five minutes pass, then restarting and checking the inbox again. |
| The message is present but the reward is missing | Open the message and use its claim control; then recheck the relevant inventory or currency total. |

The timing and fast-travel advice above comes from PC Gamer's third-party launch guide and may not describe every later patch or platform. The official launch announcement confirms mail as a reward delivery channel, but does not specify a delivery timer or universal quest condition. Check current in-game text and official notices if they differ.
