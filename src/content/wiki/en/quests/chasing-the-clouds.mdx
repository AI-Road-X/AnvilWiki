## Why this quest matters

Public launch coverage notes that completing **Chasing The Clouds** with Dr. Lewis unlocks the in-game mailbox used to claim code rewards. If a redeemed reward is missing, first confirm that this quest and the mailbox are available.

## Troubleshooting order

1. Check the quest list and confirm the quest is complete.
2. Return to the main menu and open the mailbox.
3. Change areas and check the mailbox again if delivery is delayed.
4. Record the code, time, and game version before checking official notices.

Quest conditions can change. Do not use third-party pages that ask for account credentials. See [how to redeem codes](/codes/how-to-redeem/) for the full flow.
